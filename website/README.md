# L!V!N Website

This is a static Hostinger-ready landing page that matches the current app direction.

## Local Preview

Open `index.html` in a browser, or run:

```bash
cd website
python3 -m http.server 8080
```

Then open `http://localhost:8080`.

## Hostinger Upload

1. Open Hostinger hPanel.
2. Choose the domain or subdomain for L!V!N.
3. Open File Manager.
4. Upload the contents of this `website` folder into `public_html`.
5. Confirm these files exist:
   - `index.html`
   - `styles.css`
   - `assets/livin-icon.png`
6. Visit the domain in a private browser window.

The Hostinger plugin is installed in Codex, but no callable Hostinger website tool is exposed in this thread right now. These files are ready to upload manually or through Hostinger's file tools.
